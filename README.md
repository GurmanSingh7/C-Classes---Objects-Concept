# 🎯 What Are Classes & Objects?

<div align="center">

<img src="https://readme-typing-svg.demolab.com?font=Fira+Code&size=24&pause=1000&color=7B61FF&center=true&vCenter=true&width=1200&lines=Classes+Are+Blueprints;Objects+Are+Real+Instances;Foundation+Of+Object+Oriented+Programming;Learn+Once+Build+Anything" />

</div>

### 📘 Definition

A **Class** is a blueprint or template used to create objects.

An **Object** is an instance of a class that contains data and behavior.

---

# ⚡ Complete Example

```cpp
#include <iostream>
using namespace std;

class Student
{
public:
    string name;
    int age;

    void display()
    {
        cout << "Name: " << name << endl;
        cout << "Age: " << age << endl;
    }
};

int main()
{
    Student s1;

    s1.name = "Gurman";
    s1.age = 19;

    s1.display();

    return 0;
}
```

# 🎓 Interview Questions

### Q1. What is a Class?

A blueprint used to create objects.

### Q2. What is an Object?

An instance of a class.

### Q3. Why Use Classes?

To organize data and functions together.

### Q4. Difference Between Class And Object?

Class = Blueprint

Object = Real Instance

### Q5. What Is OOP?

Programming paradigm based on classes and objects.
